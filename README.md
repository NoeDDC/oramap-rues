# Tuiles de rues ORAMAP

Voies où l'on court, découpées en tuiles de 0,05° depuis les extraits OpenStreetMap (Geofabrik), pour l'app ORAMAP par ORAPACE.
Format : `<y>/<x>.json.gz` avec `{"n": [[ref, lat, lon]...], "v": [[id, ref...]...]}` ; `couverture.json` liste les tuiles.
